# 07 — لوحة التحكم والتقارير (Dashboard & Reports)

---

## الجزء الأول: لوحة التحكم (Dashboard)

لوحة تحكم احترافية لحظية (Real-time عبر WebSocket)، قابلة للتخصيص حسب دور المستخدم، مع فلترة بالفترة والفرع.

### 1. بطاقات المؤشرات (KPI Cards)

| المؤشر | المصدر | التحديث |
|--------|--------|---------|
| عدد الموظفين | `employees` (active) | لحظي |
| الموجودون الآن | `attendance_records` (اليوم، check_in بلا check_out) | لحظي (WS) |
| المتأخرون اليوم | `attendance_records` (late_minutes > 0) | لحظي |
| الغائبون اليوم | `attendance_records` (status=absent) | لحظي |
| عدد القضايا | `cases` | يومي |
| القضايا المفتوحة | `cases` (status in open/in_progress) | لحظي |
| القضايا المغلقة | `cases` (status in closed/won/lost/settled) | لحظي |
| الجلسات القادمة | `hearings` (hearing_date ≥ الآن) | لحظي |
| الإيرادات (الفترة) | `payments` مجموع | يومي |
| المصروفات (الفترة) | `expenses` مجموع | يومي |
| صافي الربح | الإيرادات − المصروفات | يومي |
| عدد العملاء | `clients` (active) | يومي |

### 2. الرسوم البيانية (Charts)

| الرسم | النوع | المحتوى |
|-------|------|---------|
| الإيرادات مقابل المصروفات | خطي/أعمدة | آخر 12 شهراً |
| توزيع القضايا حسب الحالة | دائري (Donut) | مفتوحة/مغلقة/معلّقة... |
| القضايا حسب النوع | أعمدة | مدني/جنائي/تجاري... |
| الحضور الأسبوعي | أعمدة مكدّسة | حضور/تأخير/غياب |
| أعمار الديون (المستحقات) | أعمدة | حسب فترات التأخير |
| مسار العملاء المحتملين | قمع (Funnel) | مراحل الـ Pipeline |

### 3. الودجت (Widgets)

- **تقويم الجلسات:** عرض شهري/أسبوعي للجلسات القادمة مع ترميز لوني حسب المحامي/الحالة.
- **آخر النشاطات:** feed من `activity_logs` (من فعل ماذا ومتى).
- **أحدث التعيينات:** آخر الموظفين المعيَّنين.
- **أكثر المحامين نشاطاً:** ترتيب حسب (عدد القضايا النشطة + الجلسات المنجزة + الأتعاب المحصّلة).
- **المهام المستحقة اليوم:** من `tasks` (due_date = اليوم، للمستخدم/فريقه).
- **إشعارات النظام:** آخر الإشعارات غير المقروءة.
- **تنبيهات:** عقود/وثائق توشك على الانتهاء، فواتير متأخرة، مهل استئناف.

### 4. لوحات حسب الدور (Role-based Dashboards)

| الدور | تركيز اللوحة |
|-------|--------------|
| المدير العام | مالية شاملة + قضايا + أداء + كل الـ KPIs |
| HR | الحضور/الغياب/التأخير + الإجازات المعلّقة + التعيينات + الرواتب |
| المحامي | قضاياه + جلساته القادمة + مهامه + مذكرات مستحقة |
| المالية | الإيرادات/المصروفات + المستحقات + الفواتير المتأخرة + التدفق النقدي |
| التسويق | Leads + معدل التحويل + أداء الحملات |
| السكرتارية | جلسات اليوم + المهام + العملاء الجدد |
| الموظف | حضوره + رصيد إجازاته + كشف راتبه + مهامه |

### 5. الأداء التقني للوحة
- بيانات KPI عبر **Materialized Views / Redis Cache** تُحدَّث دورياً لتفادي استعلامات ثقيلة.
- المؤشرات اللحظية (حضور/إشعارات) عبر **WebSocket** بدل الاستطلاع (Polling).
- فلاتر: الفترة (يوم/أسبوع/شهر/سنة/مخصص) + الفرع + القسم.

## الجزء الثاني: التقارير (Reports)

جميع التقارير تدعم: **فلترة (فترة/فرع/قسم/موظف/عميل...) + تصدير PDF + Excel + طباعة + جدولة إرسال دوري بالبريد**.

### 1. تقارير الموارد البشرية

| التقرير | المحتوى | الفلاتر |
|---------|---------|---------|
| كشف الموظفين | قائمة كاملة ببياناتهم | قسم/فرع/حالة |
| تقرير الحضور | حضور/انصراف/ساعات يومي أو شهري | موظف/قسم/تاريخ |
| تقرير الغياب | أيام الغياب وأسبابه | فترة/موظف |
| تقرير التأخير | دقائق التأخير وتكراره | فترة/موظف |
| تقرير الإضافي (Overtime) | ساعات العمل الإضافي | فترة/موظف |
| تقرير الإجازات | المستهلك/المتبقي لكل نوع | سنة/موظف/نوع |
| تقرير الرواتب | مسير كامل + صافي كل موظف | شهر/فرع |
| كشف راتب فردي (Payslip) | تفصيل راتب موظف PDF | موظف/شهر |
| تقرير أداء الموظفين | نتائج التقييم والتقديرات | فترة/قسم |
| السلف والمكافآت | حركة السلف والمكافآت | فترة/موظف |
| تقرير دوران الموظفين (Turnover) | تعيينات/إنهاءات | فترة |

### 2. تقارير القضايا

| التقرير | المحتوى |
|---------|---------|
| كشف القضايا | حسب الحالة/النوع/المحامي/المحكمة/العميل |
| القضايا المفتوحة/المغلقة | إحصاء ونِسب |
| تقرير الجلسات | القادمة/المنعقدة/المؤجلة |
| أداء المحامين | عدد القضايا، نسبة الكسب، الجلسات المنجزة، الأتعاب |
| القضايا حسب العميل | كل قضايا عميل ونتائجها |
| مهل الاستئناف | أحكام قاربت مهلة الطعن |

### 3. تقارير العملاء والعقود

| التقرير | المحتوى |
|---------|---------|
| كشف العملاء | أفراد/شركات + حالتهم |
| العقود | النشطة/المنتهية + القيم |
| العقود المنتهية قريباً | تنبيه التجديد |
| ربحية العميل | إيرادات مقابل مصروفات كل عميل |

### 4. التقارير المالية

| التقرير | المحتوى |
|---------|---------|
| الإيرادات | حسب الفترة/العميل/القضية/نوع الخدمة |
| المصروفات | حسب التصنيف/القضية/الفترة |
| الأرباح والخسائر (P&L) | إيرادات − مصروفات = صافي |
| الميزانية العمومية | الأصول/الخصوم/حقوق الملكية |
| التدفقات النقدية (Cash Flow) | داخل/خارج + الرصيد |
| ميزان المراجعة | أرصدة الحسابات مدين/دائن |
| المستحقات (Receivables) | فواتير غير مسددة + أعمار الديون |
| كشف حساب عميل | حركة الفواتير والمدفوعات |
| حركة الصندوق/البنك | إيداعات/سحوبات + الرصيد |
| التقرير الضريبي | ضريبة القيمة المضافة (مخرجات/مدخلات) |

### 5. التقارير التسويقية

| التقرير | المحتوى |
|---------|---------|
| العملاء المحتملون | حسب المرحلة/المصدر/المسؤول |
| معدل التحويل | Leads → عملاء (نسبة) |
| أداء الحملات | Leads/تحويلات/عائد مقابل الميزانية (ROI) |
| مصادر العملاء | أفضل القنوات جلباً للعملاء |

### 6. تقارير المهام والتشغيل

| التقرير | المحتوى |
|---------|---------|
| المهام | حسب الحالة/المكلّف/الأولوية |
| المهام المتأخرة | تجاوزت موعدها |
| إنتاجية الموظف | مهام منجزة/متأخرة |
| سجل التدقيق (Audit) | العمليات الحساسة (Admin) |

### 7. تقنيات توليد التقارير
- **PDF:** قوالب HTML → Puppeteer/wkhtmltopdf (دعم عربي RTL كامل، شعار المكتب، ترويسة/تذييل).
- **Excel:** Maatwebsite/Excel (أعمدة منسّقة، مجاميع، تصفية).
- **الطباعة:** أوراق أنماط للطباعة (Print CSS).
- **الجدولة:** تقارير دورية (يومي/أسبوعي/شهري) تُرسَل آلياً بالبريد للمعنيين (Scheduler + Queue).
- **الأداء:** التقارير الثقيلة تُولَّد في الخلفية (Job) وتُتاح للتحميل مع إشعار عند الجهوزية؛ يفضّل تشغيلها على Read Replica.
