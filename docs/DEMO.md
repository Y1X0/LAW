# دليل العرض (Demo) — نظام LAW

تجهيز عرض حيّ لصاحب المكتب: حسابات معروفة وبيانات مرتّبة، بلا صفحات فارغة.
**بيانات وحسابات فقط — لا تغيير على أي API أو منطق أو مخطّط.**

## التشغيل (بذر البيانات)

```bash
cd backend
php artisan migrate --force            # إن لم تكن الجداول جاهزة
php artisan db:seed --class="Database\\Seeders\\DemoSeeder"
```

البذرة **Idempotent** — يمكن تشغيلها أكثر من مرة بأمان دون تكرار البيانات.

## حسابات العرض

كلمة المرور للجميع: **`Passw0rd!`**

| الحساب | البريد | الدور | يعرض |
|---|---|---|---|
| **مالك المنصّة** | `admin@demo.law` | admin (كل الصلاحيات) | **وحدة تحكّم Super Admin**: لوحة النظام · المستخدمون · الأدوار والصلاحيات · سجلّ التدقيق · الإعدادات |
| مدير الموارد البشرية | `hr@demo.law` | HR + موظف | بوابة HR كاملة + الخدمة الذاتية |
| المحامي | `lawyer@demo.law` | محامٍ + موظف | بوابة المحامي + الخدمة الذاتية |
| الموظف | `employee@demo.law` | موظف | الخدمة الذاتية فقط |

> دور `hr` يُمنح صلاحياته (employees/leaves/attendance/payroll) ضمن البذرة كبيانات فقط،
> كي تعمل بوابة HR حيّة (بدونها تُحجب بـ 403).

## البيانات المُجهّزة

- **11 موظفاً** بأقسام متنوّعة (التقاضي/الاستشارات/المالية/الموارد/الإدارة) وحالات (نشط/في إجازة/موقوف).
- **قضية `DEMO-1`** كاملة (عميل · جلسة قادمة · أطراف · مستند · أرشيف · مهمة · خطّ زمني) مسندة للمحامي.
- **4 طلبات إجازة معلّقة** (لعرض الاعتماد/الرفض).
- **18 سجلّ حضور** لآخر ثلاثة أيام (اليوم غير معتمد — لعرض زرّ الاعتماد).
- **أرصدة إجازات** لكل موظف.

## سيناريو العرض (≈10 دقائق)

### 0) وحدة تحكّم Super Admin — «كيف أتحكّم بالمنصّة» (≈2 د)
0. دخول `admin@demo.law` → **لوحة النظام**: مؤشّرات (مستخدمون · موظفون · قضايا · إجازات معلّقة) · توزيع الحالات · تنبيهات · آخر النشاط.
   - **المستخدمون** → إنشاء مستخدم · تعطيل/تفعيل · إعادة كلمة مرور · ربط موظف · إدارة الأدوار.
   - **الأدوار والصلاحيات** → مصفوفة صلاحيات دور · نسخ دور.
   - **سجلّ التدقيق** → أحداث النظام. · **الإعدادات** → الإعدادات العامّة.

### 1) بوابة الموارد البشرية — «كيف أدير المكتب» (≈4 د)
1. دخول `hr@demo.law` → **لوحة HR**: عدد الموظفين · إجازات معلّقة · غياب اليوم (عدّادات متحرّكة).
2. **الموظفون** → بحث/فلترة → فتح **ملف موظف** (تبويبات: المعلومات · العقود · الوثائق · الحضور · الإجازات · الرواتب).
3. **الإجازات** → **اعتماد** طلب (يظهر توست نجاح) → **رفض** آخر بسبب.
4. **الحضور** → مراجعة السجلات → **اعتماد** سجل اليوم / **قيد يدوي**.

### 2) بوابة المحامي — «التجربة الأساسية» (≈4 د)
5. تسجيل الخروج → دخول `lawyer@demo.law` → **الرئيسية** (لوحة المحامي المصقولة).
6. **قضاياي** → فتح **ملف القضية `DEMO-1`** → التنقّل بين التبويبات (مؤشّر ذهبي متحرّك) → **السجل الزمني**.
7. **المهام** → إكمال مهمة (توست) · **الإنجاز اليومي**.

### 3) الخدمة الذاتية للموظف — «البساطة» (≈2 د)
8. دخول `employee@demo.law` → لوحته → رصيد الإجازات → تقديم طلب → كشف الراتب.
9. إبراز: **نفس الهوية والحركات** عبر البوابات الثلاث (منتج واحد متماسك).

## مراجعة الجاهزية

- ✅ لا صفحات فارغة (كل شاشة عليها بيانات من البذرة).
- ✅ البيانات منطقية (أسماء/أقسام/تواريخ واقعية).
- ✅ الحركات وتجربة premium موحّدة (توست/تبويبات/انتقالات).
- ✅ العزل الأمني قائم (كل دور يرى نطاقه فقط — الخادم هو الحكم).
