# سجلات قرارات المعمارية (Architecture Decision Records — ADR)

هذا المجلد يوثّق **القرارات المعمارية الجوهرية** للنظام، كل قرار في ملف مستقل بصيغة موحّدة، لتكون مرجعاً واضحاً للفرق ولمن يراجع القرار مستقبلاً.

## الصيغة الموحّدة لكل ADR
| القسم | المحتوى |
|-------|---------|
| **Status** | مقترح / **معتمَد** / مستبدَل / ملغى |
| **Context** | السياق والمشكلة التي دفعت للقرار |
| **Decision** | القرار المتخذ بوضوح |
| **Alternatives Considered** | البدائل المدروسة وسبب رفضها |
| **Consequences** | النتائج الإيجابية والسلبية والمقايضات |
| **When to Revisit** | متى يُعاد النظر في القرار (محفّز التغيير) |
